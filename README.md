# Oz Docs

Keep a Markdown document you can return to by name. Open it alongside your conversation, revise the section you are discussing, and turn the finished draft into a web page.

[Connect with Claude, ChatGPT, Muse Code, or Grok](PROVIDERS.md)

> “Open my release notes, find the installation section, and suggest a clearer opening.”

## Working with Oz Docs

Documents live in your signed-in OpZero account. Read and edit operations send the target path and requested edits to Oz Docs. Publishing makes the selected content available at a public URL.

[Product documentation](https://oz-docs.mcp.opzero.sh/) · [Privacy](https://opzero.sh/privacy) · [Support](https://opzero.sh/support)
